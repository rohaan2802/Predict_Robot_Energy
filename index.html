Overview

This is Assignment 03 from ML for Robotics (CS-4090), Spring 2026. I wanted to see whether an RBF support-vector regressor could map load, speed, terrain roughness and task duration to a robot’s energy use, in watt-hours, better than a straight line.

The table is the ten-row example from the assignment brief — there is no larger log in this repository. I hard-coded those missions in the notebook, and they also sit in data/missions.csv.

I re-ran the work from src/predict_robot_energy.py. The printed test scores match the executed notebook exactly: SVR MSE 47.26049282170618, R² −0.8904197128682472; linear regression MSE 70.65189898206445, R² −1.8260759592825782. A train-mean baseline on the same two rows has MSE 31.25, which is ahead of both. With only two held-out points I am not treating the ranking as a stable result — only as what this split produced. The numbers from that run are under results/.

How the Models Are Fitted

1

Split

train_test_split(test_size=0.2, random_state=42) — eight training rows, two test rows (loads 14 and 15 kg).

2

Scale

StandardScaler fitted on the training features only, then applied to the test rows. The target is not scaled, same as the notebook.

3

SVR

SVR(kernel='rbf') with library defaults: C=1.0, epsilon=0.1, gamma='scale'. All eight training rows are support vectors.

4

Linear regression

LinearRegression() on the same scaled training features. Intercept on, no regularisation.

Out-of-range query

The brief asks for a prediction at load 25 kg, speed 2.2 m/s, roughness 7, duration 35 minutes — outside the training hull. The SVR answers 180.893219405397 Wh (the notebook’s figure). Linear regression answers 332.50 Wh.

Linear equation (standardised features)

Energy ≈ 177.5 + 24.6713×z(Load) + 13.9964×z(Speed) + 9.4609×z(Roughness) + 27.2790×z(Duration)

The intercept is the training-set mean, 177.5 Wh. Because the four inputs are nearly collinear, I would not treat these coefficients as a physical breakdown. The raw numbers are in results/.

How to run

Python 3, with the packages in requirements.txt. The CSV is already in data/.

Linux / macOS

git clone https://github.com/rohaan2802/Predict_Robot_Energy.git
cd Predict_Robot_Energy
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 src/predict_robot_energy.py

Windows

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src\predict_robot_energy.py

That prints the notebook’s test scores, the extra training metrics and the out-of-range query, and writes files under results/. Optional flags: --data-dir, --results-dir and --no-plots. The same steps are in notebooks/i222327_Mohammad_Rohaan_A_03_ML.ipynb.
